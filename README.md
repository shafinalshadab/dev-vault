# 🚀 DevVault - Daily Code & Snippet Manager

![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)
![FastAPI](https://img.shields.io/badge/FastAPI-0.100+-green.svg)

![License](https://img.shields.io/badge/License-MIT-yellow.svg)

DevVault is a clean, modern, full-stack application designed for developers to store, organize, and track their daily code snippets, algorithms, and micro-projects. Built with a high-performance **FastAPI** backend and an intuitive **Tailwind CSS** frontend.

---

## ✨ Features

- 📝 **Daily Snippet Logging:** Store daily code snippets with titles, language tags, and timestamps.
- 🏷️ **Tag-based Categorization:** Organize code by algorithms, APIs, features, or custom topics.
- ⚡ **Fast API Endpoints:** Built using FastAPI for ultra-fast performance and clean OpenAPI documentation.
- 🎨 **Developer-friendly UI:** Sleek, dark-mode focused frontend powered by Tailwind CSS.
- 🔓 **CORS Enabled:** Ready for multi-origin architecture and decoupled deployment.

---

## 🛠️ Tech Stack

- **Backend:** Python, FastAPI, Uvicorn, Pydantic
- **Frontend:** HTML5, JavaScript (ES6+), Tailwind CSS
- **API Standard:** RESTful API Architecture
